============================================================
Magic WAND - 프로젝트 아키텍처 및 폴더 구조 가이드
============================================================

이 문서는 AI 에이전트와 새로운 개발자가 프로젝트의 전체적인 구조를 
빠르게 파악하고 일관성 있게 코드를 작성하도록 돕는 핵심 길잡이입니다.
새로운 요구사항을 구현하기 전, 반드시 이 문서를 참조하여 알맞은 폴더와 방식을 선택하세요.

0. 공통 작업 지침
------------------------------------------------------------
- `AGENTS.md`와 `CLAUDE.md`는 이 프로젝트뿐 아니라 모든 작업의 기본 지침입니다.
- 작업 행동, 호칭, 배포, 보안, 터미널 안전 규칙은 두 문서를 우선 적용합니다.
- 프로젝트 루트의 `AGENTS.md` / `CLAUDE.md` 사본은 전역 기준 파일과 같은 내용으로 유지합니다.
- 개발, 수정, 테스트 작업은 원칙적으로 `dev` 브랜치에서 진행합니다.
- 사용자가 GitHub 최신화/연동을 요청하면 `main`과 `dev` 브랜치를 모두 최신 커밋으로 맞춰 푸시합니다.

1. 핵심 기술 스택
------------------------------------------------------------
- Desktop App: Electron + HTML/CSS/JavaScript
- Local Data: portable JSON files under hidden `MagicWAND_Data/` beside the executable
- Packaging: TBD (later: Electron Builder or similar Windows .exe packaging)
- Legacy Prototype: Python + PySide6 files remain under `src/magic_wand/` for reference until migration is complete.

2. 주요 디렉토리 및 파일 역할 (Directory Structure)
------------------------------------------------------------
- `package.json`: Electron 앱 실행 명령 및 Node 패키지 설정
- `electron/main.js`: Electron 창 생성, 기능 모듈 등록, 현재 화면 PDF 저장을 담당하는 지휘자
- `electron/preload.js`: 화면 코드가 쓸 수 있는 안전한 기능을 기능별 묶음
  (ipRecords, network, system, export, app)으로 연결
- `electron/core/run-command.js`: PowerShell 실행, 외부 명령 실행, 동시 작업 처리 등
  모든 모듈이 함께 쓰는 공용 도구
- `electron/core/portable-data.js`: 숨김 폴더 `MagicWAND_Data/`에 JSON 자료를 읽고 쓰는 공용 함수
  (`getDataFileForRead`, `getDataFileForWrite`). 새 저장 코드는 직접 경로를 만들지 말고 이 함수를 쓴다.
- `electron/modules/`: 기능별 모듈 폴더. 각 파일은 `register(ipcMain)`로 자신의 기능을 등록한다.
  - `network.js`: 공인 IP, PC IP 정보, IP 대역 사용 현황, 네트워크 장애 진단
  - `ip-records.js`: IP 목록 저장/불러오기 (JSON 파일)
  - `system-info.js`: PC 사양과 설치된 소프트웨어 목록 조회
  - `hardware-check.js`: 디스크 용량, 물리 디스크 건강, SMART 상세값, 메모리, 배터리, GPU, 온도 센서, 시스템 이벤트 점검
  - `threat-scan.js`: 실행 중 프로세스·시작 프로그램·설치 SW 키워드, 사용자 지정 검사대상 폴더, Microsoft Defender, YARA 룰 기반 위험 소프트웨어 점검
  - `control-panel.js`: 네트워크 어댑터 DHCP/고정 IP 설정 변경, 컴퓨터 이름 변경 (관리자 권한 필요)
  - `windows-tools.js`: 제어판, 네트워크 연결, 장치 및 프린터, 프로그램 제거/변경, CMD 바로가기 실행
  - `printer.js`: 프린터 목록 조회, 기본 프린터 설정, 테스트 인쇄, 대기열/스풀러 관리
  - `share.js`: 폴더 공유 등록/중지, 공유 목록 조회
  - `security.js`: 정품 인증·CD-KEY·BitLocker 상태, 로컬 사용자 계정, 파일 숨김 처리
  - `secure-erase.js`: 파일·폴더·드라이브 복구 불가 영구 삭제 (0 덮기 / DoD 3회)
  - `form-maker.js`: 양식지(증빙 문서) 보관함 저장/불러오기/관리
  - `file-tools.js`: 파일·폴더·아이콘 선택, ZIP 압축 백업, 작업 진행 상태·취소, 네트워크 드라이브 전송, 저장 경로·웹 바로가기 세트 관리, 아이콘 지정 웹 바로가기 생성
  - `admin-work.js`: 요청 접수, 업무 체크리스트, 거래처, 비품/소모품 수불, 구매 진행, 계약 만료, 빠른 메모 등 행정 업무 대장 저장
  - `asset.js`: 자산 등록/목록 저장·불러오기. PC·노트북·모니터·복합기·NAS 핵심 정보와 보증 만료 임박 강조
  - `health.js`: PC 성능(건강) 점수 산출, 부팅 속도, 하드웨어 온도 게이지, 점검 전·후 스냅샷 저장/비교
  - `cleanup.js`: 휴지통·임시폴더·브라우저 캐시 등 안전 경로 청소(용량 스캔/삭제). 삭제는 확인 절차 필요
  - `driver.js`: 설치된 장치 드라이버 목록 조회, 선택 폴더로 드라이버 백업(`Export-WindowsDriver`)
  - `event-log.js`: Windows 이벤트 로그(오류/경고) 분석, 흔한 오류 한글 설명, TXT 저장
  - `net-monitor.js`: 네트워크 속도·핑 실시간 모니터 시작/정지(주기 폴링, 창 종료 시 타이머 정리)
  - `sw-license.js`: 소프트웨어 라이선스(제품키·좌석·만료일) 보관함 저장, 만료 임박 정렬·강조
  - `remote.js`: 자산 목록 IP를 재사용한 다중 PC 읽기 전용 원격 점검(핑/WinRM 확인/사양 조회)
  - `achievements.js`: 점검·백업 횟수 누적 도전과제·배지 카운터
  - `ui-settings.js`: 작업 완료 토스트/사운드/데스크톱 알림 등 UI 설정 저장
  - `license.js`: 정품키(.lic) 서명검증·만료확인·계정 로그인·시계 되돌리기 방어를 담당하는 실행 게이트
  - `file-rename.js`: 폴더 안 파일 이름 일괄 변경(미리보기/적용). 미리보기·충돌 검출 후 토큰 확인이 있어야 적용, 시스템 폴더 차단
  - `settings-backup.js`: `MagicWAND_Data/` 자료를 ZIP로 백업/복원(Compress/Expand-Archive). 정품키·인증 파일은 제외
  - `win-update.js`: Windows 마지막 업데이트 설치일·재부팅 필요·대기 업데이트 조회, 업데이트 설정 열기
  - `startup-apps.js`: 시작 프로그램(Run 레지스트리) 조회·켜기/끄기. 끄기는 삭제가 아니라 값 백업 후 비활성(되돌리기 가능)
  - `recovery.js`: USB/SD 이동식 디스크 검사·복구. 이동식 디스크만 대상으로 하고, 복구 실행은 확인 토큰이 필요
- `renderer/index.html`: 앱 화면 구조
- `renderer/styles.css`: 앱 디자인
- `renderer/app.js`: 페이지 전환(라우팅), IP 목록 관리, 검색, 공용 함수(switchPage, showToast)
- `renderer/pages/`: 화면별 동작 모듈 폴더
  - `system-info.js`: PC정보 화면(사양/소프트웨어) 동작
  - `hardware-check.js`: 하드웨어점검 화면 동작
  - `threat-scan.js`: 의심프로그램 화면 동작
  - `control-panel.js`: 네트워크 설정 화면 동작 (어댑터 IP·컴퓨터 이름 변경)
  - `printer.js`, `share.js`, `security.js`: 점검 : 프린터/공유폴더/계정 및 보안 화면 동작
  - `form-maker.js`, `form-manager.js`: 양식지 제작·관리 화면 동작
  - `label-maker.js`: 장비/IP 라벨지 미리보기·인쇄, 라벨 규격 직접 입력 화면 동작
  - `integrated-check.js`: 통합 점검 화면 동작 (여러 점검을 모아 증빙 문서나 PDF로 저장)
  - `file-tools.js`, `web-shortcut.js`: 백업 및 전송, 저장 경로 관리, 아이콘 포함 바로가기 세트 저장·불러오기 화면 동작
  - `admin-work.js`: 행정 상황판, 거래처, 비품수불, 구매 진행, 계약만료, 요청접수, 업무 체크리스트, 빠른 메모 화면 동작
  - `asset.js`: 자산 등록 폼, 자산 목록 필터·통계 그래프, 자산 상세 PDF 저장 화면 동작
  - `health.js`: PC 성능 점수 게이지, 부팅 속도·온도 위젯, 항목별 점검 내역, 전·후 비교 화면 동작
  - `cleanup.js`: 정리 대상 선택·스캔 결과·진행 상태 화면 동작
  - `driver.js`: 드라이버 목록 조회·백업 화면 동작
  - `event-log.js`: 점검 : 이벤트 로그 화면 동작
  - `sw-license.js`: 라이선스 관리 등록·목록 화면 동작
  - `remote.js`: 원격 일괄 작업(대상 PC 선택·읽기 전용 점검) 화면 동작
  - `file-rename.js`: 파일명 관리 규칙 입력·미리보기·적용 화면 동작
  - `startup-apps.js`: 시작 프로그램 목록·켜기/끄기 화면 동작
  - `recovery.js`: 외부 저장장치 복구용 이동식 디스크 목록, 검사, 복구 실행 화면 동작
  - `settings-backup.js`: 설정 백업/복원 동작 (백업 및 전송 화면 안 패널)
  - `win-update.js`: Windows 업데이트 상태 점검 동작 (점검 : 계정 및 보안 화면 안 패널)
- `renderer/menu.js`: 사이드 메뉴 그룹 접기/펼치기 동작
- `renderer/lock.html`, `renderer/lock.js`: 정품키 잠금/로그인 화면(앱 진입 전 게이트)
- `tools/`: 별도 설치 없이 앱에 포함할 보조 실행 파일 위치
  - `tools/smartctl/`: SMART 상세 진단용 `smartctl.exe`와 `drivedb.h` 위치
  - `tools/hardware-probe/`: LibreHardwareMonitor 기반 센서 보조 진단 스크립트와 DLL 위치
  - `tools/yara/`: 위험 소프트웨어 점검용 YARA 실행 파일과 보조 탐지 룰 위치
- `MagicWAND_Data/`: 포터블 실행파일 옆에 자동 생성되는 숨김 로컬 데이터/정품키 저장 위치
- `data/`: 예전 개발 단계에서 쓰던 로컬 데이터 위치. 새 저장 코드는 새 폴더가 비어 있을 때만 이전 자료 복사용으로 참조한다.

3. 아키텍처 특이사항 (주의)
------------------------------------------------------------
- 첫 단계는 복잡한 DB 없이 JSON 파일로 저장합니다.
- Magic WAND는 포터블 프로그램입니다. 겉으로 보이는 파일은 exe 하나를 원칙으로 하며, 저장이 필요한 자료와 정품키는 exe 파일 내부나 `%APPDATA%`가 아니라 실행파일 옆 숨김 폴더 `MagicWAND_Data/`에 저장합니다.
- `MagicWAND_Data/`는 Windows에서 숨김 속성으로 자동 처리합니다. 자료 파일을 새로 추가할 때는 직접 경로를 만들지 말고 `electron/core/portable-data.js`의 공용 함수를 사용합니다.
- 정품키 파일은 `MagicWAND_Data/magicwand.lic`, 인증 상태 파일은 `MagicWAND_Data/.mwstate`, 인증 보호 파일은 `MagicWAND_Data/.mwsecret`에 둡니다. 예전 방식처럼 exe 옆에 `magicwand.lic`가 있으면 실행 시 숨김 폴더로 옮겨 연동합니다.
- 기존 버전의 `%APPDATA%\Magic WAND` 또는 개발용 `data/`에 남은 JSON 자료는 새 위치에 자료가 없을 때만 자동 복사합니다. 새 자료를 저장한 뒤에는 `MagicWAND_Data/`를 기준으로 판단합니다.
- IP 목록 기능을 기반으로 이후 네트워크 스캔, 장비 상태 확인, 내보내기 기능 등을 단계적으로 추가합니다.
- Electron 전환 중에는 Python/PySide6 버전을 즉시 삭제하지 않고, 새 Electron 앱이 안정화된 뒤 정리합니다.
- IP 대역 스캔은 PC와 네트워크 장비에 부담을 주지 않도록 기본 최대 254개 주소까지만 조사합니다.
- 앱은 진짜 전체화면 모드가 아니라 일반 창을 최대화해서 시작합니다. 상단 메뉴바는 숨기고 Windows 창 버튼은 유지합니다.
- 왼쪽 사이드메뉴는 `PC 관리`, `자산 관리`, `문서 관리`, `행정 업무`, `업무 도구`, `프로그램 종료` 순서로 구성합니다.
  - `PC 관리`: `PC 기본 정보`, `PC 성능 점검`, `통합 점검`, `점검 : 하드웨어`, `점검 : 소프트웨어`, `점검 : 이벤트 로그`, `점검 : 네트워크`, `점검 : 프린터`, `점검 : 공유폴더`, `점검 : 계정 및 보안`
  - `자산 관리`: `자산 등록`, `자산 목록`, `원격 일괄 작업`
  - `문서 관리`: `양식지 제작`, `양식지 관리`, `라벨지 생성`
  - `행정 업무`: `상황판`, `거래처`, `비품수불`, `구매 진행`, `계약만료`, `요청접수`, `업무 체크리스트`, `빠른 메모`
  - `업무 도구`: `백업 및 전송`, `바로가기 관리`, `파일명 관리`, `시작 프로그램 관리`, `외부 저장장치 복구`, `시스템 최적화`, `장치 드라이버 관리`, `라이선스 관리`
  - 메뉴 그룹 제목은 접기/펼치기 버튼이며, 동작은 `renderer/menu.js`가 담당합니다.
  - `점검 : 네트워크`에는 와이파이·공유기 찾기, 속도·핑 모니터 기능을 통합합니다.
  - `점검 : 하드웨어`, `점검 : 소프트웨어`, `점검 : 이벤트 로그`는 각각 별도 페이지로 분리합니다.
  - `점검 : 계정 및 보안`에는 Windows 업데이트 상태 점검 패널을 통합합니다.
  - `백업 및 전송` 화면에는 설정 백업/복원 패널을 함께 둡니다.
  - 위 메뉴 항목은 모두 실제 기능으로 구현되었습니다.
  - 정품키 잠금 화면(`renderer/lock.html`)을 통과해야 본 화면으로 진입합니다.
- 기능별 모듈 구조를 따릅니다. 새 기능은 `electron/modules/`에 모듈 파일을 만들어
  `register(ipcMain)`를 내보낸 뒤 `main.js`의 `registerIpcHandlers`에 등록합니다.
  화면은 `renderer/pages/`에 파일을 추가하고 `index.html`에 메뉴/페이지/스크립트를 더합니다.
- 관리자 권한이 필요한 기능(IP 변경, 프린터/공유, 프로그램 설치/삭제 등)을 위해,
  배포용 .exe는 항상 관리자 권한으로 실행되도록 패키징 단계에서 설정할 예정입니다.
  (개발 중 `electron .` 실행에는 적용하지 않습니다.)
